PROJECT 1: Customer Analytics Portfolio – E-Commerce

Business Impact: ₹197K Revenue at Risk Identified | 98% Churn Prediction Accuracy | Revenue Concentration Analysis

Business Objective

Develop integrated customer analytics system to identify revenue exposure, protect high-value customers, and optimize retention spending through data-driven prioritization.

Problem Statement

E-commerce businesses struggle to allocate limited retention budgets efficiently. Without understanding revenue concentration and churn risk interaction, companies overspend on low-impact customers while under-protecting high-value segments.

Solution Architecture

Three-Tier Analytics Framework:

1. Churn Risk Prediction — Identified customers likely to disengage within 90-day window using Logistic Regression on behavioral features (recency, purchase velocity, customer lifetime, return behavior).

2. Customer Lifetime Value (CLV) — Predicted 6-month CLV using probabilistic models (BG/NBD + Gamma-Gamma), revealing 33% of customers contribute 88% of revenue.

3. Revenue-at-Risk Intelligence — Combined churn probability with CLV to quantify financial exposure: Revenue at Risk = Churn Probability × CLV (6 months)

PROJECT 3: E-Commerce Recommender System

Hybrid Recommendation Engine | TF-IDF + Collaborative Filtering | 3.3× Accuracy Improvement

Business Objective

Develop hybrid recommendation engine balancing content-based precision with collaborative filtering diversity, optimizing for both accuracy and catalog coverage.

Technical Architecture

Adaptive Hybrid Engine combining:
• Content-Based: TF-IDF vectorization (1,535 terms) with cosine similarity
• Collaborative Filtering: User-based and item-based approaches on sparse matrix
• Adaptive Blending: Dynamic α adjustment based on user activity level
• Cold users (few ratings): 85% content-heavy → Warm users (many ratings): 30% collaborative-heavy

Performance Comparison

Engine Hit@5 Hit@10 Coverage Diversity
Content-Based 2.7% 7.3% 77.4% 0.000
CF Item-Based 0.0% 0.0% 84.0% 0.792
Hybrid Adaptive 16.7% 24.0% 83.4% 0.312

Hybrid_Adaptive wins on all accuracy metrics (3.3× improvement) while maintaining 98% personalization

Dataset & Scale

Products: 500 items across 5 categories (Electronics, Clothing, Home, Books, Sports)
Users: 300 active users with demographic data
Interactions: 7,456 ratings (1-5 scale) with purchase indicators
Sparsity: 95% sparse user-item matrix (typical e-commerce scenario)

Key Features

  • ✓ Handles cold-start problem effectively through adaptive alpha
  • ✓ Balances accuracy, coverage, and diversity for production deployment
  • ✓ Mean-centered cosine similarity removes user rating bias
  • ✓ Streamlit interface for real-time recommendations
